## 从域名到上线：动手搭建的六个步骤

流程本身不复杂，按下面六步走完就能上线。

1. **注册域名**：简短好记、带品牌词，优先 .com。Namecheap、Namesilo、Namebright、Dynadot 这几家都提供免费的域名隐私保护，后两家价格更低。相中某个域名前，可以用时光机查历史快照看有没有黑历史，再用 SEMrush 或 Ahrefs 查外链情况。域名务必注册在自己名下，别托管在第三方手里。
2. **解析与证书**：A 记录把域名指向服务器 IP，CNAME 常用于子域名和 CDN——Cloudflare 免费版就能做全球加速；再配上 HTTPS 证书。做欧美市场，主机和 CDN 节点尽量选北美或欧洲。
3. **安装并初始化 WordPress**：后台设中文、前台英文或多语言；内容没建完之前，先在 Setting → Reading 勾选“禁止搜索引擎收录”，别让空页面被谷歌抓走；固定链接（Permalink）选 Post Name 格式，这是对 SEO 最友好的结构。
4. **装主题**：Astra 和 GeneratePress 是两个轻量首选，Astra 初始加载能做到 0.5 秒以内，GeneratePress 压缩后只有 10 KB，两款免费版就够外贸站用；想要拖拽式设计再配 Elementor。
5. **装插件**：询盘表单用 WPForms，SEO 用 Yoast 或 RankMath，图片优化 Imagify，缓存插件提速，备份用 All in one WP Migration，安全加 Wordfence。产品超过 10 个的话直接上 WooCommerce，分类页和详情页会自动生成。插件别贪多，装多了拖慢速度是 WordPress 的老毛病。
6. **上线前检查**：用谷歌的移动端适配工具测一遍手机端，缓存加 CDN 调好加载速度，最后到 Google Search Console 提交网站、放开第 3 步的收录限制。

## 页面结构与询盘系统：决定转化的部分

排名做上去只是第一步，B2B 外贸站的最终目标是询盘。经典结构是：Home、About Us、Products（分类页 + 详情页）、Service、Blog、Contact Us。首页、关于我们这类页面用 Page 配可视化编辑器来做，产品页交给 WooCommerce 自动生成。

几个直接影响转化率的细节值得单独记：首页放醒目的询盘入口和 WhatsApp、邮件直达按钮，缩短客户操作路径；About 页放真实客户评价和国际认证标志；做多语言版本时给不同语种页面配置 hreflang 标签，避免搜索引擎判重。询盘表单记得配 SMTP 邮件服务，保证客户提交的信息实时落到企业邮箱。

## SEO 与流量：上线之后拉开差距的事

独立站和平台渠道是互补关系。头部外贸企业基本是阿里国际站、展会、EDM 几条腿一起走，而询盘数量和质量最好的两条，恰恰是阿里国际站和谷歌独立站。外国客户习惯通过 Google 搜供应商——搜不到你、却能轻松翻到同行，丢的不只是那条询盘，还有“你是正规企业”的印象分。

关键词布局的常规做法：首页放 Factory、Manufacturer、Supplier 这类 B 端属性词，产品分类页放主关键词，详情页放长尾词，博客持续更新行业内容引流。再配上 Google Analytics 和 Facebook Pixel 追踪询盘来源，LinkedIn、YouTube 的社媒矩阵负责品牌曝光，有预算的叠加 Google Ads 精准获客。
